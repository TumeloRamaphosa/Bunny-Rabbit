# Daily Agent Routine — Reptile Loop for Pharma Funding

**Goal:** Autonomous funding loops that source capital, validate markets, execute manufacturing deals across SA/Eswatini/Rwanda.

## Cadence (Daily at Midnight SAST)

### Phase 1: Market Intelligence (09:00 SAST)
- **Agent:** Market Scout
- **Task:** Scan pharmaceutical import data (SA, Eswatini, Rwanda)
  - Current import volumes
  - Import tariffs + VAT
  - Price gaps vs. local manufacturing
- **Output:** Import deficit report → Katlego's dashboard

### Phase 2: Deal Sourcing (10:00 SAST)
- **Agent:** Investment Hunter
- **Task:** Find pharma manufacturing assets
  - Idle manufacturing capacity (SA, Rwanda)
  - Licensing opportunities (GMP, SADC cert)
  - Funding announcements (DFI, Impact investors)
- **Output:** Deal pipeline → Katlego for scoring

### Phase 3: Financial Scoring (11:00 SAST)
- **Agent:** Katlego (Human decision maker)
- **Task:** Rate deals on
  - CAPEX needed
  - Import substitution potential
  - Cash flow to payback
  - Risk (regulatory, supply chain)
- **Output:** "Warm leads" tagged for outreach

### Phase 4: Funding Loop (14:00 SAST)
- **Agent:** Fundraiser
- **Task:** Outreach to funding sources
  - DFI (IFC, DBSA, AfDB)
  - Impact investors
  - Strategic partners (Natalia, Global Markets)
- **Output:** 3-5 warm meetings/week target

### Phase 5: Relationship Check-in (19:00 SAST)
- **Agent:** Bunny Bot
- **Task:** Daily question to you + Katlego
  - "What excited you today about pharma manufacturing?"
  - "How did we show up for each other?"
- **Output:** Obsidian knowledge base (relationship signal)

## Agent Roster
| Agent | Role | Daily Task | Output |
|-------|------|-----------|--------|
| Market Scout | Intelligence | Import data scan | Report |
| Investment Hunter | Deal sourcing | Asset + funding hunt | Pipeline |
| Katlego (You) | Financial scoring | Deal evaluation | Warm leads |
| Fundraiser | Outreach | DFI/investor contact | Meetings |
| Bunny Bot | Relationship | Daily questions | Obsidian log |

## Success Metric
- 3-5 warm funding conversations per week
- 1 manufacturing partnership by Q4 2026
- SA/Eswatini/Rwanda presence established
